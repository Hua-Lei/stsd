# 004 项目文档归 Access 持有

状态：已采纳，2026-11-17。尚待与 `src/document` 草稿的负责人对齐

## 背景

需求文档和接口文档随项目版本产生，用例库、Agent 都需要读取它们。`src/document` 的草稿把文档作为独立模块，并按文档类型各自维护整数版本号，与项目版本没有关联。

## 决定

文档附属于项目版本，由 Access 在添加项目版本时一并保存，之后不可修改。文档分为需求文档和接口文档两类。其他模块通过 Access 的读接口获取文档。

## 理由

用例分析里添加项目版本时就要同时提供文档，项目版本是文档唯一合理的归属，这样"某个项目版本对应哪些文档"有唯一出处。

## 后果

`src/document` 的草稿需要改为以项目版本为键，或并入 Access，否则会出现两处存放文档。
