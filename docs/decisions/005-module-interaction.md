# 005 模块之间如何交互

状态：已采纳，2026-11-17

## 背景

模块之间需要传递两类信息：对方已经确定的事实，以及刚刚发生、需要对方响应的事情。早期设计让调用方传入快照来避免同步读取，但调用方传入的内容无法被信任。

## 决定

读取事实时调用对方的读接口，读接口返回不可变的只读对象，不返回聚合本身。事件用于通知对方有事发生。每个模块只持有其他模块对象的 id。

Task 通过用例库的读接口确认修订已冻结。执行器通过 `task_id` 读取任务，再通过用例库的读接口读取实现。

## 理由

已冻结的修订不可变，所以读取它不会读到变动中的内容，不需要用事件维护本地副本，也不需要传递快照。

## 后果

执行器依赖 Task 和用例库的读接口。用例库需要保证已冻结的修订在所属测试点被软删除后仍然可读。Agent 与用例库的交互方式尚未决定，见 [agent.md](../modules/agent.md)。
