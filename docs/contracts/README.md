# 跨模块契约

这里放多个模块依赖的同一个事实：实现声明的形状、事件的载荷。它们不属于任何单个模块——实现声明由用例库校验、由执行器解释、由结果系统保存其结论，写进任何一家的文档，另两家就得抄一遍，然后开始各自漂移。

对应的代码放在 `stsd.shared` 下。用例库和执行器都只依赖它，不 import 对方，也不构成环。

契约的字段是破坏性变更的边界：新增字段兼容，改名、删除或改变语义不兼容。改这里之前先确认所有依赖方。

*   [implementation-spec.md](implementation-spec.md) 测试点实现的声明
*   [events.md](events.md) 模块间事件的载荷
