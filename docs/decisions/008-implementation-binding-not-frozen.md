# 008 执行时的绑定不属于冻结内容

状态：已采纳，2026-11-24

## 背景

pytest 实现要跑起来需要被测地址。草稿设计把它和 python 版本一起放进实现的 `requirements`，随修订一起冻结。

## 决定

实现只声明它需要哪些绑定的名字，值由执行器在执行时取得并填入，由结果系统记下实际用的值。否决了把被测地址写进冻结内容。

## 理由

回归测试是同一条冻结修订打到新部署，换环境复跑也是。地址一旦进了冻结内容，一条修订就只对一个地址有效，而冻结不可撤销，没有补救办法，只能另开新修订——这正是 [002](002-implementation-and-freeze.md) 要避免的那种不可补救状态。

python 版本不同，它说的是这份实现必须在什么环境里被构建，换一个版本本质上是另一份实现，跟着冻结是对的。两者放在一起才是问题。

## 后果

多一层绑定机制：执行器要知道从哪里取值。目前取自 Access 项目上的 `web_config`，它是否足够描述一次执行的目标环境尚未确认。结果里必须记下实际用的绑定，否则旧结果无法解释。
